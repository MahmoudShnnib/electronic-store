# Electronic Store

Production-ready e-commerce platform for electronics built with **Laravel 12**, **Vue 3 + TypeScript + Inertia.js**, **Tailwind CSS**, and **PostgreSQL**. See [ARCHITECTURE.md](ARCHITECTURE.md) for the full system design, ERD, role matrix, and lifecycle documentation.

## Features

- **Storefront** — catalog with search/autocomplete, filters, sorting, product variants & specifications, wishlist, guest + authenticated carts with merging, coupons, multi-step checkout (COD / bank transfer), order tracking, returns, reviews (verified purchase + moderation), English/Arabic with RTL.
- **Custom admin dashboard** — KPIs & charts, product/category/brand/specification CRUD, multi-warehouse inventory with an immutable movement ledger, stock adjustments & transfers, suppliers & purchase orders with partial receiving, order management with a strict status state machine, returns/refunds, customer management, coupon management, review moderation, reports with CSV export, staff users & roles (Spatie permissions), read-only audit logs, settings.
- **REST API `/api/v1`** — Sanctum bearer tokens for the future mobile app, API Resources everywhere, rate limiting, idempotent checkout.
- **Integrity** — every stock change goes through a row-locked transaction that writes an `inventory_movements` ledger entry; totals are always recomputed server-side; overselling is prevented with `SELECT … FOR UPDATE`.

## Requirements

- PHP 8.3+ (built on 8.5), Composer
- PostgreSQL 15+ (17 recommended)
- Redis (queues, cache, rate limiting)
- Node 20+ (Vite build)

## Setup

```bash
composer install
npm install

cp .env.example .env        # already configured for local pgsql + redis
php artisan key:generate

createdb electronic_store
createdb electronic_store_test

php artisan migrate --seed  # seeds roles, default warehouse, settings, demo catalog
php artisan storage:link

npm run build               # or: npm run dev
php artisan serve           # + php artisan queue:work for emails/notifications
```

**Default super admin:** `admin@store.test` / `password` — change immediately.

## Testing

```bash
php artisan test            # Pest feature tests (uses electronic_store_test DB)
```

Critical flows covered: stock ledger consistency, overselling prevention, purchase-order receiving, checkout totals/coupons/idempotency, order state machine, cancellation stock release, returns & refunds, permissions per role, storefront rendering, API auth/authorization/IDOR.

## Roles

`super_admin` (everything) · `admin` (all but user/role/settings management) · `inventory_manager` (catalog, stock, purchasing) · `order_manager` (orders, returns, refunds, customers) · `customer` (storefront).
